# MCP tool reference - UACC and SnareVec

Generated by `python dev/toolref.py` from each server's source. `*` = required.

|---|---|---|

| `snarevec__browser_click` | selector*, nth, force, confirm, tab_id | Click an element by CSS selector, using a real trusted mouse event |
| `snarevec__browser_close_tab` | tab_id* | Close a tab by id. |
| `snarevec__browser_execute_js` | script*, confirm, tab_id | Run JavaScript in the page and return its value |
| `snarevec__browser_fill_form` | fields*, submit_selector, confirm, tab_id | Fill several fields in one call - one round trip instead of one per field |
| `snarevec__browser_get_page_info` | tab_id | URL, title, load state, scroll position and viewport size of a tab |
| `snarevec__browser_list_tabs` | - | List the open http(s) tabs with their ids, URLs and titles |
| `snarevec__browser_navigate` | url*, timeout_ms, tab_id | Load a URL in the user's real browser and wait for it to finish |
| `snarevec__browser_new_tab` | url, active | Open a new tab, optionally at a URL, and return its id. |
| `snarevec__browser_press_key` | key*, modifiers, selector, confirm, tab_id | Press a single key, optionally with modifiers, optionally after focusing an element |
| `snarevec__browser_query` | selector*, limit, tab_id | Run a CSS selector and return the matched elements' text, key attributes, visibility and position |
| `snarevec__browser_screenshot` | full_page, format, tab_id | Capture the tab as an image |
| `snarevec__browser_scroll` | direction, amount, selector, confirm, tab_id | Scroll the page, or a scrollable container when you name one with `selector` - which is what you want for a modal, a sidebar or an infinite list, where scrolling the document behind it does nothing. |

| `snarevec__configure_search` | rerank_enabled, rerank_model, rerank_candidates, rerank_top_k, rerank_max_chars | Turn cross-encoder reranking on or off and tune it |
| `snarevec__crawl_site` | collection*, url*, include, exclude, max_pages, max_depth, delay_s, same_host, obey_robots, render, topic | Walk a website into a collection, following links |
| `snarevec__create_collection` | name* | Create an empty collection to hold sources |
| `snarevec__create_profile` | collection*, kind, group, backend_id*, target_id*, name, prefix, hybrid, sparse_model, contextual, chunk_strategy, chunk_size, chunk_overlap, bind | Bind a collection to an embedding model and a storage target |
| `snarevec__embed_collection` | collection*, only_pending | Embed everything queued in a collection and deliver the vectors to its configured storage target |
| `snarevec__get_setup` | - | Show the daemon's whole configuration: embedding backends, storage targets, profiles, collections, which optional components are installed, and current search settings |
| `snarevec__install_component` | component | Install an optional dependency |
| `snarevec__list_collections` | - | List the SnareVec collections on this machine, with how many sources each holds and which index they use |
| `snarevec__search_collection` | collection*, query*, top_k | Semantic search over one SnareVec collection |
| `snarevec__snarevec_status` | - | Whether the local SnareVec daemon is running, its version, and how many collections it holds |
